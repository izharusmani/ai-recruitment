# AI Recruitment

AI Recruitment is a modern hiring platform designed to streamline candidate sourcing, screening, and onboarding using intelligent automation.

## Features

- Resume parsing and candidate profile generation
- Automated job matching based on skills and experience
- AI-powered screening questions and candidate scoring
- Interview scheduling with calendar integration
- Applicant tracking system with status updates
- Recruiter dashboard and analytics
- Candidate communication templates and notifications
- Role-based access control for administrators, recruiters, and hiring managers
- Resume search and filtering by skills, experience, location, and keywords
- Data export for reporting and compliance

## Getting Started

1. Clone the repository.
2. Install dependencies.
3. Configure environment variables.
4. Run the application.

## Benefits

- Reduces time to hire
- Improves candidate quality and fit
- Centralizes recruitment workflows
- Provides actionable hiring insights
